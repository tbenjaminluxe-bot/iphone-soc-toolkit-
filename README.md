### ⚙️ What it does
- **IOC Extractor:** Regex for IPs, URLs, MD5/SHA256 hashes (same logic SIEMs use)
- **Risk Scoring:** Weighted scoring (malicious URL 70 + internal IP 20 + hash 20 = 110 CRITICAL)
- **SOC Actions:** Auto-suggests BLOCK, Reset MFA, Report CIRT / Isolate Host
- **Casebook:** Saves investigations to CSV for Tier 2 handoff

### 💡 Why I built it
As MTN NOC Engineer, I saw phishing alerts with IOCs but no quick triage tool. Built this during shifts on my iPhone to bridge NOC monitoring → SOC investigation.

### 🛠️ Tech Stack
Python3, Regex, Threat Intelligence, Incident Response, SIEM Logic
